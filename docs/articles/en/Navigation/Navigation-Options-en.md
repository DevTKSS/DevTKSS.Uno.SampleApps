# How To: Choose Navigation Options for an Uno App

Every application that comprises more than a single page benefits from the presence of a well-thought-out **navigation**.

In Uno Apps, we can use two types of navigation:

- `Frame` navigation (as in WinUI Apps)
- `Regions`, i.e. using `Uno.Extensions.Navigation`

To get a good overview of the possibilities that `Uno.Extensions.Navigation` offers you, you can, for example, take a look at the [Tutorial: Navigation with Uno Extensions](xref:DevTKSS.Uno.ExtensionsNavigation.Overview.en). There we will look at how to handle or implement the `Uno.Extensions.Navigation` and the `NavigationView` in a Xaml-based Uno application.

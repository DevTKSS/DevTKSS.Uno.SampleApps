# Möglichkeiten für die Navigation in einer Uno App

Jede Anwendung, die mehr als eine einzige Seite umfasst profitiert von dem vorhanden sein einer durchdachten **Navigation**.

In Uno Apps können wir hierfür zwei Arten der Navigation verwenden:

- `Frame`-Navigation (wie in WinUI Apps)
- `Regions`, also unter Verwendung der `Uno.Extensions.Navigation`
